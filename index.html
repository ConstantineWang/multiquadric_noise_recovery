Abstract

This project presents significant improvements to the Expectation, Maximization, and Switching for Superquadrics (EMS)\cite{liu2022robust} algorithm for recovering multiple superquadric surfaces from 3D point clouds. Our enhanced approach addresses key limitations in the original implementation through three main contributions: (1) adaptive outlier detection using Principal Component Analysis (PCA) for intelligent clustering decisions, (2) comprehensive numerical stability improvements preventing computational failures, and (3) refined parameter initialization strategies based on statistical analysis. Experimental results demonstrate that our modifications achieve more robust surface fitting, especially when multiquadric fitting is conducted.
